# User guide

1. Sign in with a staff username and password. There is no public registration.
2. Use **Products** to search, add, view, edit, or delete unused products. Zero and low stock are labeled automatically.
3. Use **Customers** for contact records. A sale may instead remain a walk-in transaction.
4. Use **Staff Accounts** to create login accounts, replace passwords, and manage optional avatars. Leaving password blank during edit preserves it.
5. Choose **Record Sale**, select an in-stock product, optionally select a customer, enter a whole-number quantity, and submit. The displayed preview is informational; the server recalculates and checks everything.
6. Use **Sales History** to search/filter immutable transactions and open a receipt-style detail view.
7. Use **Log out** in the header. Protected pages require a valid staff session on the next request.

If a deletion is blocked, the record participates in sales history and must be preserved. If a product stock edit reports stale data, reload the edit page and apply the intended value to the newest stock count.
